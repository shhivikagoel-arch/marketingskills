# Daily Publish - Audit Checklist

Run every draft through all three passes before it lands in the `day-n` folder. Record the outcome of each pass in the piece's file and in `SUMMARY.md`.

## Pass 1 - Fact check

For each factual claim in the draft (statistics, dates, quotes, product capabilities, competitor references, named studies):

- [ ] The claim traces to a source captured during brainstorming (URL or user-provided material).
- [ ] The source actually says what the draft claims - open it, don't rely on a summary.
- [ ] Numbers are quoted with the same scope as the source (time period, market, sample).
- [ ] Quotes are verbatim and attributed.
- [ ] Anything unverifiable is cut or rewritten as opinion/experience - never kept as fact.

## Pass 2 - Brand guidelines

- [ ] Voice and tone match the brand's documented style.
- [ ] Approved terminology used; banned words/topics absent.
- [ ] Claims policy respected (no superlatives, guarantees, or comparisons the brand hasn't approved).
- [ ] No invented testimonials, customer names, or metrics.
- [ ] Language pass completed with the `copy-editing` skill (grammar, clarity, no filler).

## Pass 3 - Channel optimization

For the specific channel the piece publishes to:

- [ ] Length within the channel's limits (character counts, thread structure, script runtime).
- [ ] Hook/format follows the channel's current conventions (see `social` platform references).
- [ ] Hashtags, mentions, links, and CTAs match the channel's norms and limits.
- [ ] Visual asset specs (dimensions, aspect ratio) noted for image/video pieces.

## Outcomes

- **READY** - all three passes clean; enters the day folder.
- **REVISED** - failed a pass, was fixed, re-audited clean; note what changed.
- **BLOCKED** - failed re-audit; excluded from the day's set, reason recorded in `SUMMARY.md`.
